# Codex Base capability catalog

This catalog separates the portable plugin from the full Linux Nix/Home Manager
installation. “Plugin” means the contents installed by
`codex-base@bioinformatist-codex`; “Nix” includes the Home Manager module,
packages, global configuration, and linked unnamespaced skills. Explicit and
conditional triggers are intentional: installation alone does not run a skill.
The Plugin and Nix columns report only what Codex Base provides or configures.
Users can configure Mintlify or Context7 independently or get either
configuration from another plugin.

When remote GitHub CI is the only remaining step, query its status at most
once, then report the exact head, run link, and remaining acceptance.
Report pending as pending, not passed. Do not watch, poll, or schedule follow-up
unless the user explicitly requested monitoring. That request need not use a
specific phrase or language.
