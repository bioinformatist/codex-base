# Verification diagram brief

Show necessary tests, stepwise verification and simplification, independent
review, and checkpoint as the main path. Visual and Bend are conditional paths
that can both apply. Visual takes originals and collection evidence and returns
observations with locations and uncertainty to implementation and review.
Bend takes an actual Bend implementation and selected properties and returns
proof evidence and coverage limits to review. Neither replaces independent
review; neither proves other languages or runtimes. Do not imply automatic
installation or migration to Bend.

Keep English and Chinese topology equivalent on a 1200 × 620 canvas, using
the workflow palette, system fonts, real text, `role="img"`, and localized
title and description. Use no external assets. Parse both SVGs, render each
at 1200 and 720 px with the locked `rsvg-convert`, and inspect the previews
for overlap, clipping, and readability. Keep PNGs private.
